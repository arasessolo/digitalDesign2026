L2 - 1er año

Enfoque: Creación de páginas web (HTML & CSS)

  • Navarro Cox y Lloveras Lemos 1A

    Crearon una página web desde cero utilizando Inteligencia Artificial para generar textos e imágenes con el fin de presentar la escuela "Aprender hoy para transformar el mañana".

  • De la Serna 1D

    Diseñó una página web destinada a comunicar y recomendar las mejores series y películas de la historia.

  • Castillo 1D

    Desarrolló un sitio web para presentar las principales características e información del juego de PlayStation Forza 6.

L3 - 2do año

Enfoque: Data Analytics

  • Sanmiguel, Silva y Langlet 2D

    Realizaron una encuesta para evaluar el impacto de la moda en el medioambiente y construyeron un dashboard interactivo para comunicar sus hallazgos. Para lograrlo, crearon y aplicaron la encuesta, limpiaron los datos, construyeron diagramas de relación, trabajaron con tablas dinámicas, gráficos e identificaron insights clave.

  • Bonofiglio, Machado y Fitte 2D

    Realizaron un informe analítico y dashboard visual que evalúa la relación entre la carga deportiva extraescolar, la flexibilidad académica y las prioridades de los estudiantes, estructurado con métricas y gráficos estadísticos.

L4 - 3er año

Enfoque: Programación con Python

  • Tolosa 3A

    Desarrollo de un menú interactivo en Python con dos minijuegos (Adivinar el número y Batalla), estructurado mediante funciones, manejo de variables, condicionales y ciclos de repetición.

  • Cottone 3C

    Simulación en Python para la automatización de un Rover de exploración, implementando lectura de sensores, algoritmos de perforación y navegación guiada por condiciones climáticas.

L5 - 4to año

Enfoque: Desarrollo con Python y Streamlit

  • Di Benedetto, Day y Della Giustina 4A

    Panel de control interactivo para directores técnicos que permite registrar futbolistas, asignar puntuaciones por rendimiento, administrar listas de espera de fichajes y visualizar métricas clave en tiempo real.

  • Cormenzana y Delorenzi 4B

    Aplicación web estilo Spotify desarrollada con Streamlit, enfocada en la gestión de catálogos musicales, cola de reproducción interactiva, métricas de popularidad (KPIs) e interfaz personalizada con CSS.

  • De Foronda y García Mansilla 4B

    Aplicación web en Streamlit para la gestión integral de un refugio de animales, que incluye padrón de mascotas, historial de vacunación, validación de aptos para adopción y lista de espera de adoptantes.
